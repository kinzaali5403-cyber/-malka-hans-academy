# Malka Hans Digital Academy — Android Studio WebView Project

Package ID: `com.malkahans.academy`  
Version: `1.0.0` (1)

## Option 1: Build APK in the Cloud (No PC / No Android Studio Needed)
1. Create a new repository on **GitHub** (https://github.com/new).
2. Extract this ZIP and upload all files (make sure the `.github` folder is included).
3. Open the **Actions** tab in your GitHub repository.
4. The **Build Android APK** workflow will compile automatically (~2 minutes).
5. Click the completed workflow run and download **malka-hans-digital-academy-debug-apk** under **Artifacts**, then unzip and install the `.apk` on your Android phone.

## Option 2: Build Locally with Android Studio
1. Extract this ZIP and open the folder in **Android Studio**.
2. Wait for Gradle Sync to finish.
3. Click **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Find the compiled APK at `app/build/outputs/apk/debug/app-debug.apk`.
